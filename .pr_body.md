## Summary

Comprehensive fix for the D2 scoring pipeline that was crushing scores with compounding penalties, plus frontend UX improvements and D1 parity.

## What was broken

**All 494 signals showed as Type F (LTF Weak).** Zero A/B/C/D/E signals appeared. Root cause: D2's LTF pipeline had three compounding penalty layers that pushed median D2 score from ~15 down to 7 (p25=0, p75=22). With 465/494 coins at score 0-7, nothing passed any signal type threshold. D1 had the same problem — median ~9, 92% REJECTED.

## Changes

### D2 Pipeline Fixes

**1. Halve all D2 penalties** (`backend/engines/ltf_pipeline.py`)
- `_ATR_PENALTY`: 10 → 5
- `_RANGE_PENALTY`: 8 → 4
- `_FLOW_PENALTY`: 10 → 5
- `_NO_SMC_PENALTY`: 10 → 5
- `_FALLBACK_PENALTY`: 15 → 8
- `_FATAL_FLAW_PENALTY`: 20 → 8
- `_NO_CANDLES_PENALTY`: 20 → 10

**2. Fix D2 volume check** — was comparing last 3 forming candles (still building) to 20-bar avg. Now uses last 3 closed candles only, threshold relaxed from 0.3x to 0.5x.

**3. Relax fatal flaw OB deviation** — 8.0% → 12.0% (15M breakouts legitimately move 10%+ past OB).

**4. Populate D2 structure tags** — added MSB, OB, FVG, liquidity data to signal dict so D3/frontend can display structure tags on cards.

**5. Fix `entry_precision` NameError** — variable was referenced but never defined. Added 0.0 placeholder (ltf_scanner.scan_entry() overwrites with actual value).

### Signal Type Classification

**6. Remove `nascent_move` hard gate for Type B** — was blocking Type B classification entirely. Type B now uses EP gate only.

**7. Lower Type B EP gate** — `TYPE_B_ENTRY_PRECISION_GATE`: 10 → 5 (matches realistic EP scoring ranges).

### D1 Parity

**8. Halve D1 engine penalties** — same proportional reductions as D2. D1 median was ~9 with 92% REJECTED. Now should produce 100+ approved coins.

### Frontend UX

**9. Health badge to top-right** — moved health/status from bottom of page to header top-right. Compact pill showing Live/Starting dot + coin counts. Updates on every health poll cycle (3s).
